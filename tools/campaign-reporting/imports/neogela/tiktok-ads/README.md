# TikTok Ads — import settimanale Neogela

Ogni lunedì mattina prima delle 8:00 esporta da TikTok Ads Manager e salva qui i CSV.

## Come esportare

TikTok Ads Manager → Reports → Custom Report → seleziona dimensioni e metriche → Export CSV.

Nomina i file così:

| Report | Nome file |
|---|---|
| Campagne | `campaigns_2026-06-08_2026-06-14.csv` |
| Gruppi di annunci | `adgroups_2026-06-08_2026-06-14.csv` |
| Annunci | `ads_2026-06-08_2026-06-14.csv` |

## Colonne necessarie

**Campagne:** Campaign name, Campaign status, Budget, Cost, Impressions, Clicks, CTR, CPC, Conversions, Conversion value, ROAS

**Gruppi di annunci:** Campaign name, Ad group name, Ad group status, Cost, Impressions, Clicks, CTR, CPC, Conversions

**Annunci:** Campaign name, Ad group name, Ad name, Cost, Impressions, Clicks, CTR, Video views, Video play actions, Average video play time
